# 🔳 QR Code Generator

**Turn your text and links into QR codes in seconds!**

A beginner-friendly Python project that allows you to create customized QR codes from any text or URL. Choose your favorite colors, give your QR code a custom name, and save it as a PNG image.

---

## 🌟 What Can You Do With This Project?

With this application, you can:

- 🔗 **Convert Links:** Turn any website URL into a QR code.
- 💬 **Convert Text:** Create QR codes containing your personal messages.
- 🎨 **Choose Colors:** Customize QR code and background colors.
- 📝 **Custom File Names:** Give your QR code any name you want.
- 💾 **Save Images:** Automatically save QR codes as PNG files.
- ✅ **Input Validation:** Prevent empty inputs and invalid colors.

## 👀 How It Works

Creating a QR code is simple!

1. Enter your text or website URL.
2. Choose your QR code color.
3. Select a background color.
4. Enter your preferred file name.
5. Generate your QR code!
6. Find your image inside the `generated_qr` folder.

## 🖼️ Example

Imagine you want to share your favorite website with a friend.

**Input:**
```text
https://www.google.com
```

**Output:**

A QR code containing your website link, ready to save and share!

## 🚀 Getting Started

Want to try it yourself? Follow these easy steps.

**Step 1: Clone the Repository**

```bash
git clone https://github.com/MH-Topu1/QR_Code_Generator.git
```

**Step 2: Open the Project Folder**

```bash
cd QR_Code_Generator
```

**Step 3: Install the Required Library**

```bash
pip install "qrcode[pil]"
```

**Step 4: Run the Project**

```bash
python main.py
```

That's it! You're ready to generate your first QR code. 🎉
